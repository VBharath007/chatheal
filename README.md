# ChatHeal — Luxury Holistic Wellness Platform

A Next.js, TypeScript, and Framer Motion luxury wellness application featuring executive wellness spaces, interactive circadian rhythm dashboards, dietary logs, and evidence-based nutrition programs.

## Features
- **Luxury Botanical Aesthetic**: Mint, forest green, warm cream, and gold palette with subtle glassmorphic surfaces.
- **Client & Coach Portal**: Interactive wellness space, real-time hydration tracker, metabolic overview, and telehealth appointment booking.
- **Recipes & Seasonal Kitchen**: Small-batch whole food culinary journal, interactive ingredient breakdown, and artisan pantry.
- **Programmes & Consultations**: Comprehensive wellness plans, circadian optimization, and personalized lifestyle coaching.
- **Fully Responsive**: Optimized for high-resolution desktop displays, tablets, and iOS/Android mobile viewports.

## Tech Stack
- **Framework**: Next.js 15 (App Router)
- **Language**: TypeScript
- **Styling**: Vanilla CSS Modules, CSS Variables, and Glassmorphic Tokens
- **Icons**: Lucide React
- **Animations**: Framer Motion
- **Fonts**: Playfair Display (Serif), Inter / Roboto (Sans-Serif)

## Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run local development server:**
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

4. **Production Build:**
   ```bash
   npm run build
   npm start
   ```
